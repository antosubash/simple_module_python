# Historical plans and designs

Status: superseded (see [canonical design specs](../superpowers/specs/)).

This directory is a historical archive. New design documents belong in
[`docs/superpowers/specs/`](../superpowers/specs/); implementation plans belong
in [`docs/superpowers/plans/`](../superpowers/plans/).

Use a `Status: current`, `Status: implemented`, or `Status: superseded (see …)`
header on new design documents and update it as work lands or is replaced.
For existing documents, follow status banners and current framework reference
docs; the newest date alone does not establish the intended state.
