# First-run app fixes from the 0.0.45 field test (#914–#919)

Six issues filed against a fresh `smpy new` app, shipped as four PRs.

## PR 1 — `/admin` in every app; quickstart corrections (#914, #919)

**Problem.** The sidebar "Administration" link and the AdminLayout badge go to
`/admin`, which only this repo's host serves (`host/routes.py` `admin_overview`
+ `host/client_app/pages/Admin.tsx`); a scaffolded app 404s. The quickstart
promises it, documents `curl /api/orders` as `200 []` (it is 401), and names a
test file the scaffold does not write.

**Approach.** Move the admin overview into `simple_module_hosting`, exactly as
the setup wizard is (#351): `simple_module_hosting/admin_overview/` with the
route (same gating: signed in, and admin or holding any admin-sidebar entry)
and `pages/Overview.tsx`, mounted by `app_builder` and registered by
`gen-pages` like `Setup/Wizard`. Its three strings move from `host/locales` to
the `hosting` namespace (en/de/es). This repo's host drops its copy.
Rejected: copying the route, page and a `host/locales` catalog into the host
template (duplicates the gating per app, forces a host catalog).

**Docs (#919).** Quickstart step 4: `create-admin` without `--password` (it
prompts) and a passphrase example; step 7: anonymous `curl` returns 401, open
`/orders/` signed in instead; step 8: `modules/orders/tests/web/crud/test_orders_crud.py`
(and `uv run pytest modules/orders`); same password fix in `installation.md`.

**Tests.** Hosting route tests moved from `host/tests/test_admin_overview_access.py`;
a scaffold test that the app has no admin route of its own and `/admin`
renders for an admin.

## PR 2 — `uv sync` keeps the app installed; adding a module during `make dev` (#916, #915)

**#916.** The workspace root template gains a dependency on the host package
through `[tool.uv.sources] <host> = { workspace = true }`, so a plain `uv sync`
installs host and every module instead of uninstalling them. `smpy new` runs
and prints the workspace-correct install (`make install`); `create-module`
inside an app workspace prints the app flow (`smpy add …`, `make install`,
`make migration`, `make test`) instead of `cd module && uv sync --extra dev`.

**#915.** uvicorn's reloader keeps the `sys.path` it started with, so a module
installed after `make dev` started cannot be imported until a restart. When an
entry point is found but its package cannot be imported, discovery says so:
"installed after this process started — restart `make dev`" instead of the
misleading "No module named '<x>.module'". Rejected: re-reading `.pth` files at
reload (re-implements editable installs); a watcher that restarts the
supervisor (new dev dependency, more moving parts than the problem).

## PR 3 — SQLite expression-index warning (#917)

The autogenerate hook warns about every expression index in the metadata, before
the revision has re-emitted them, and points at a make target and doc that only
exist in this repo. Fix: re-emit first, then warn only about expression indexes
on tables the revision touches that it did not emit (so a fresh app's initial
schema and an unrelated module migration print nothing). One advice helper
for the three messages (autogenerate warning, SM026, `migrate` note): this
repo's make target and doc only when they exist, otherwise "verify with
`alembic upgrade heads` against a PostgreSQL `SM_DATABASE_URL`".

## PR 4 — generated module pages use their locale file (#918)

The base module templates hardcode English while shipping `locales/en.json`;
the `framework_repo` overlay already has keyed pages (`t(keys.<pkg>.…)`,
`useApiErrorToast`). Make the keyed pages the only pages and delete the
overlay copies. A scaffolded app generates `keys.<pkg>` with `make gen-i18n`
(also on dev boot); `create-module` / `smpy add` next steps say so.
**Risk:** a module scaffolded outside any app (standalone repo) has no host to
generate keys; if its `tsc` cannot pass, the standalone variant keeps
hardcoded strings and the README says how to switch.

## Decisions made

- Four PRs, in the order above (PR 1 also unblocks the quickstart's `/admin`).
- Admin overview strings become `hosting.admin.*`.
- #915 gets a precise error message, not automatic reloading.
- #917 keeps SM026 and the `migrate` note (SQLite really cannot verify), only
  their advice changes.
