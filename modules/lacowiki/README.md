# LacoWiki module

Migration wireframes for the LacoWiki land-cover validation platform.

This module ships mid-fidelity Inertia pages for the eight LacoWiki domains (datasets, legends, sampling, validation, reports, account) plus the design-system browser. Pages are display-only — no real data models yet.

Routes registered under `/lacowiki/`:

- `/lacowiki/` — wireframes browser (Overview / Design system / Wireframes)
- `/lacowiki/datasets`, `/lacowiki/legends`, `/lacowiki/sampling`, `/lacowiki/validation`, `/lacowiki/reports`, `/lacowiki/account`

Shared primitives, chrome, and styles live in `@simple-module-py/ui/lacowiki/*`.
